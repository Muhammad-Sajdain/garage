# Garage API

This is a Node.js + Express starter project with a migration-ready structure.

## Structure

- `src/` - Application source code
  - `routes/` - API routes
  - `controllers/` - Request handlers
  - `services/` - Business logic
  - `middleware/` - Middleware
  - `config/` - Configuration
- `migrations/` - Database migration files and runner

## Run

```bash
npm install
npm run dev
```

## Health endpoint

```bash
GET /api/health
```
